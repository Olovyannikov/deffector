# Демо

В репозитории одна модель effector (`demo/shared`), отрисованная во всех поддерживаемых конфигурациях.
Модель собрана babel-плагином effector, поэтому sid везде одинаковые: трейс, записанный в React,
воспроизводится во Vue, Solid или Next.js.

## Живое демо

React-демо работает прямо на этом сайте: [откройте живое демо](/demo/){target="_self"} с установленным
расширением, затем DevTools → **deffector**. Его API имитируется на странице, поэтому ничего не уходит
из браузера.

## Запуск

```sh
npm install                 # из корня репозитория
npm run build               # агент, demo/shared, расширение, standalone
```

Загрузите расширение из `packages/extension/dist` (см. [Установка](/ru/guide/installation)); после
пересборки нажмите ↻ на его карточке в `chrome://extensions`.

## Что нажимать

![Демо на React: Sign up, Counter и «Bugs to catch» (здесь накрыто плашкой блокировки после перехода в прошлое)](/screens/x-app-locked.png){.screen}

- **Counter** — простейший случай: [Log](/ru/panel/log), переход назад (двойной клик по строке,
  <kbd>Ctrl</kbd>+<kbd>[</kbd> / <kbd>Ctrl</kbd>+<kbd>]</kbd>, <kbd>Esc</kbd> — в настоящее).
- **Sign up** — валидация, `sample` с `filter` (кнопка **Create account** при невалидной форме →
  «filter = false»), эффект с задержкой, подсказки email (гонка ответов видна во вкладке
  [Effects](/ru/panel/effects)). Email со словом `taken` — ошибка сервера.
- **Greet later (no scopeBind)** — вызов события из `setTimeout` без `scopeBind`: красная строка «вне
  scope», приветствие в UI не появляется. Кнопка рядом — исправленный вариант.
- **Quick fill (double update)** — `combine`, объявленный раньше `sample`, пересчитывается дважды: бейдж
  `2×` и объяснение во вкладке **Почему**.
- **Name = “crash”** — исключение в `.map`: ошибка в логе и в Health.

## Что проверить руками

- **Блокировка прошлого.** Двойной клик по строке лога: страница накрыта, клик ничего не меняет,
  <kbd>Esc</kbd> на странице возвращает в настоящее. **Разрешить клики** в баннере панели — изменения
  идут в ветку.
- **Сохранённые фильтры** (воронка в панели инструментов): сохраните regex, включите **Подсветка** — у
  строк появится цветная точка; **Не записывать** — подходящие транзакции не хранятся, а переходы назад
  всё равно показывают верное состояние.
- **Снимок** (Stores → **Снимок →**): вставьте `{ "sid": значение }`, посмотрите diff, примените.
- **Заметка и ссылка** на транзакцию (кнопки в инспекторе); при экспорте выбранный шаг попадает в
  `meta.focus`, а импорт откроет трейс на нём.
- **Последовательность** — вкладка в инспекторе: юниты как линии жизни, операторы как стрелки, `✕` там,
  где filter не пропустил.
- **Подмена эффектов** (Effects → **Подмена эффектов**): pending, значение, ошибка, задержка, свой
  хендлер.
- **Graph**: путь «От → До», группы по файлу / фабрике / домену / модели (двойной клик раскрывает),
  подписи операторов на рёбрах.
- <kbd>Ctrl</kbd>+<kbd>K</kbd> — палитра команд. Клик по файлу открывает Sources на нужной строке.
- **Лаборатория → Health**: аварийная остановка цикла, «прочитал $qty до обновления», «создан N раз»,
  «вне scope», цикл только через события, **Проверить производные сторы**.
- **Firefox:** `npm run build`, затем `about:debugging` → **Этот Firefox** → **Загрузить временное
  дополнение** → `packages/extension/dist-firefox/manifest.json`.

## Трейс между демо

Traces → **Сформировать JSON** → **Скачать .json**. Во втором окне (или в другом демо) — Traces →
вставить → **Проверить совместимость** → **Воспроизвести в новом scope**. Пароль в трейсе замаскирован
с сохранением длины.

Все демо прогоняются сквозными тестами: `npm run e2e` из корня.
