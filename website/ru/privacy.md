# Политика конфиденциальности

_Обновлено: 17 октября 2026_

deffector — инструмент разработчика для приложений на effector: расширение для браузера «deffector —
effector DevTools», npm-пакеты `@deffector/agent` и `@deffector/standalone` и этот сайт документации.

## Расширение ничего не собирает

Расширение не собирает, не хранит на серверах, не продаёт и не передаёт никакие персональные данные и
данные о просмотре страниц. Оно не делает собственных сетевых запросов и не содержит аналитики,
рекламы и трекеров.

Что оно делает на вашем компьютере:

- **На localhost и на разрешённых вами сайтах** небольшой content script проверяет, работает ли на
  странице агент deffector (пакет `@deffector/agent`, который разработчик добавляет в своё
  приложение). На страницах без агента скрипт больше ничего не делает. К другим сайтам у расширения
  доступа нет: оно просит доступ к сайту, только когда вы нажимаете «Разрешить на этом сайте».
- **На страницах с агентом** он передаёт сообщения между агентом и панелью deffector в Chrome DevTools:
  события приложения, значения сторов и вызовы эффектов — чтобы разработчик мог их отлаживать. Эти
  сообщения не покидают браузер и хранятся только в памяти, пока открыты DevTools.
- **Настройки панели** (язык, фильтры, пресеты) сохраняются в локальном хранилище расширения на вашем
  компьютере.
- **Трейсы** выгружаются только по нажатию кнопки экспорта — файлом или в буфер обмена. Значения,
  похожие на секреты (пароли, токены), в них замаскированы.

## Отдельное приложение

`@deffector/standalone` работает на вашем компьютере и по умолчанию принимает подключения только с
него (127.0.0.1). Оно пересылает сообщения между приложением и панелью и ничего не сохраняет.

## Этот сайт

Сайт размещён на GitHub Pages, который может вести журнал посещений, как описано в
[заявлении GitHub о конфиденциальности](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
Чтобы показать число звёзд, сайт запрашивает его у публичного API GitHub; cookies он не ставит.
