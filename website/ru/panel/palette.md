# Палитра команд

<kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> на macOS) или кнопка с лупой в панели
инструментов открывают палитру команд: одно поле для вкладок, действий, юнитов и транзакций.

![Палитра с введённым «email»: email.changed, email.reset, email.$value и другие юниты с их файлами](/screens/x-palette.png){.screen}

Введите несколько букв («Команда, юнит или #транзакция…»), выбирайте <kbd>↑</kbd> / <kbd>↓</kbd>,
выполняйте <kbd>Enter</kbd>, закрывайте <kbd>Esc</kbd>.

| Группа         | Что в ней                                                                                                                                                                                                   | Результат                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **Вкладка**    | Log, Stores, Effects, Graph, Traces, Health (с клавишами 1–6)                                                                                                                                               | переключает вкладку                                  |
| **Действие**   | Начать / остановить запись · Очистить лог · Экспорт трейса · Импорт трейса · Commit · Revert · Вернуться в настоящее · Блокировать / разрешить клики в прошлом · Проверить производные сторы · Сменить язык | выполняет его; рядом показаны сочетания клавиш       |
| **Юнит**       | все события, сторы и эффекты с файлами                                                                                                                                                                      | стор открывается в Stores, остальные юниты — в Graph |
| **Транзакция** | последние 300 транзакций, `#12 greetingShown`                                                                                                                                                               | открывает её в логе                                  |

## Сочетания клавиш

| Клавиши                                                     | Действие                                                                        |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd>                                | палитра команд                                                                  |
| <kbd>1</kbd> … <kbd>6</kbd>                                 | Log, Stores, Effects, Graph, Traces, Health                                     |
| <kbd>Ctrl</kbd>+<kbd>[</kbd> / <kbd>Ctrl</kbd>+<kbd>]</kbd> | на одну транзакцию назад / вперёд                                               |
| <kbd>Esc</kbd>                                              | назад в настоящее (и на странице тоже); закрывает палитру и сохранённые фильтры |
| <kbd>Ctrl</kbd>+<kbd>L</kbd>                                | очистить лог                                                                    |
| <kbd>Ctrl</kbd>+<kbd>S</kbd>                                | экспорт трейса                                                                  |
| <kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>Enter</kbd>               | в логе: выбрать строку, перейти к ней                                           |

<kbd>Ctrl</kbd> и <kbd>⌘</kbd> взаимозаменяемы. Цифры работают, когда фокус не в поле ввода.

## Ссылки на файлы

Везде, где у юнита известно место в коде, — в дереве шагов, в Stores, в Health — имя файла является
ссылкой. В расширении она открывает панель DevTools **Sources** на этой строке. Если файл не удаётся
сопоставить со скриптом страницы (и в отдельном приложении), путь `файл:строка` копируется в буфер
обмена: «Скопировано src/model.ts:42: откройте в редакторе».
